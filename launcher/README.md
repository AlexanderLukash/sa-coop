# SA COOP Launcher

Кросплатформний настільний лаунчер для Windows x64 та Linux x64.
Інтерфейс українською; сама GTA і мод на Linux працюють через Wine.

Версія 0.2.1 використовує темно-фіолетове оформлення за наданими прикладами
в `launcher/пример/`: приглушене тло GTA, округлі панелі, вузька бічна навігація
та вибір персонажів з фіолетовим підсвічуванням. Стиль описаний у `src/renderer/theme.css`.
Годинник показує локальний час; верхній лічильник відображає учасників поточного лобі.

Версія 0.2.2 очікує підтвердження від мода перед позначкою «на сервері».
Кожен запуск має окремий токен у `launcher.ini`; стан мода записується в
`coop/launcher.ini.status.json`. Старий файл стану не може підтвердити новий запуск.
Потрібен мод `0.2.5-mp11` із цією підтримкою (протокол 19).

## Можливості

- Вибір установленої GTA San Andreas 1.0 US, перевірка розміру `gta_sa.exe`.
- Після вибору сумісної гри лаунчер автоматично встановлює ModLoader, SilentPatch, Widescreen Fix, Framerate Vigilante, SkyGfx та Open Limit Adjuster у папки ModLoader; наявні файли не перезаписуються.
- Завантаження `SA-COOP.zip` з GitHub Releases вибраного репозиторію.
- Прогрес і скасування завантаження, перевірка SHA-256, якщо GitHub надає digest.
- Захист від виходу ZIP за межі папки, збереження конфігурацій, резервування й відкат файлів у разі помилки.
- Приватні LAN-лоббі на комп’ютері хоста: UDP-пошук, запрошення, пароль, до 8 учасників, готовність.
- Стартовий вибір «Хостити / Приєднатись», назва лобі та вибір LAN/VPN-адаптера.
- Динамічні картки лише підключених гравців: скін, нік, власна кнопка готовності/старту.
- Глобальний профіль або окремі нік і скін для поточного лобі; 299 персонажів із пошуком, категоріями та офлайн-мініатюрами.
- Пізнє приєднання: вхід у запущене лобі, вибір персонажа й окремий запуск GTA.
- Перевірка однакового SHA-256 `coop.asi` перед входом у лоббі.
- Нікнейм, роздільність, віконний режим, голосовий чат, гучність і мікрофон.
- Назва сервера, кількість гравців, дружній вогонь, порти, нова гра або слот збереження.
- Запуск Windows без оболонки; Linux — через вибраний Wine і Wine prefix.

## Як грати

1. Відкрийте «Файли гри» та оберіть папку з `gta_sa.exe`. Моди комфорту завантажаться автоматично; якщо пакет недоступний або конфліктує з наявним файлом, лаунчер покаже його назву.
2. Встановіть однаковий мод усім гравцям. Лаунчер завантажує SA COOP з GitHub Release
   репозиторію, вказаного в налаштуваннях.
3. На стартовому екрані оберіть «Хостити гру» або «Приєднатись». Хост задає назву лобі
   й вибирає адресу LAN чи VPN-адаптера (наприклад, Radmin VPN або Hamachi).

Посилання Framerate Vigilante можна перевизначити, якщо ModDB недоступний: створіть `mod-sources.json` у папці userData лаунчера з полем `{"framerateVigilanteUrl":"https://…"}`.
4. Хост натискає «Створити лобі та чекати друзів». Решта знаходить лобі за його назвою
   або вставляє повне запрошення на кшталт `sacoop://192.168.1.2:7790/ABCDEF`.
5. У своїй картці кожен може змінити нік і скін; прапорець глобального профілю визначає,
   чи вибір застосовуватиметься в наступних лобі. Параметри сервера доступні лише хосту.
   Учасники натискають «Я готовий», хост — «Почати сесію». Спочатку запускається GTA
   хоста; після появи ігрового сервера GTA запускається в учасників з автопідключенням.
6. Не закривайте лаунчер під час сесії. Щоб завершити, закрийте GTA, потім вийдіть із лоббі.
7. До вже запущеного лобі теж можна зайти, якщо є місце. Оберіть персонажа й натисніть
   «Приєднатися до гри» у власній картці. Інші учасники продовжують грати.

Для скінів і підтвердження підключення потрібен мод `0.2.5-mp11`, протокол 19, з поточного `dist/SA-COOP.zip`.
Попередній мод mp8 не читає поле скіна в мережевому повідомленні. Установіть нову збірку всім.
Модель застосовується в ігровому світі; сюжетні катсцени можуть використовувати свої моделі,
а магазини одягу та сюжетні перевдягання потребують окремої ігрової перевірки з не-CJ скінами.

Ігрові файли GTA не розповсюджуються. Потрібна власна встановлена копія 1.0 US.
Лаунчер перевіряє підтримуваний розмір exe; це не повна перевірка справності гри.

## Локальна мережа

Усі комп’ютери мають бути в одній доступній IPv4-мережі. На хості дозвольте:

| Порт | Призначення |
| --- | --- |
| TCP 7790 | Лоббі, готовність і запуск (змінюється в налаштуваннях) |
| UDP 7791 | Автоматичний пошук лоббі |
| UDP 7788 | Ігровий сервер (змінюється в налаштуваннях) |

Якщо Wi-Fi блокує broadcast або ізолює клієнтів, спробуйте адресу вручну або іншу мережу.
На комп’ютері з VPN чи кількома адаптерами виберіть потрібну адресу при створенні лобі.
Скопійоване запрошення використовує її. Якщо broadcast не проходить через VPN,
введіть IP хоста в поле запрошення: лаунчер надішле адресний UDP-запит і знайде назву лобі.
PortProton — середовище запуску гри на Linux, а не VPN; для мережі потрібні LAN або VPN.
Лоббі призначене для довіреної локальної мережі: WebSocket не використовує TLS.
Облікові записи та центральний сервер не потрібні. Публічного інтернет-браузера серверів немає.

## Linux

Установіть Wine з підтримкою 32-бітних Windows-програм та всі потрібні для вашої GTA компоненти.
У додаткових налаштуваннях можна вказати шлях до `wine` та окремий Wine prefix.
Запуск використовує native/builtin overrides для `vorbisFile`, `dinput8` та `dsound`
для поширених ASI loaders і не виконує shell-команди.
Вибирайте справжній Linux-шлях до папки гри, наприклад `/home/user/Games/GTA-SA`.
На Linux назви `gta_sa.exe`, `coop.asi` та `coop` мають відповідати регістру.
Лаунчер нативний; GTA, мод і сервер залишаються Windows-бінарниками.
Повний ігровий сценарій на Linux/Wine потребує перевірки на реальній установці GTA.

## Розробка та пакування

Потрібен Node.js 24 LTS.

```sh
cd launcher
npm ci
npm test
npm start
npm run test:ui
npm run test:native    # Windows; спочатку build.py dist і build_launcher_probe.py
npm run dist:win       # на Windows: NSIS installer і portable exe
npm run dist:linux     # на Linux: AppImage і deb
```

Результат — у `launcher/out/`. Workflow `.github/workflows/launcher.yml` тестує
і пакує застосунок на Windows та Ubuntu. На Linux CI UI-тест іде через Xvfb;
параметр `--no-sandbox` використовується лише в цьому CI-тесті.
Пакети не підписані сертифікатом видавця.

`npm test` перевіряє конфігурації, запис INI, інсталяцію/відкат, шкідливий ZIP,
8 WebSocket-клієнтів, готовність, хостові права, сумісність мода, зміни ніків/скінів,
пізнє приєднання, повторний вхід у гру та реальний UDP-пошук.
`npm run test:ui` запускає справжній Electron, перевіряє навігацію, збереження налаштувань
і обмеження запуску, вибір персонажа та масштабування восьми карток до мінімального
вікна; знімки — у `launcher/test-results/` (`home.png`, `lobby-1.png`, `lobby-2.png`,
`crew.png`, `crew-small.png`, `skin-picker.png`, `late-join.png`).
Ці перевірки не запускають GTA та не замінюють тест на кількох ігрових комп’ютерах.

`npm run test:native` інсталює справжній зібраний ZIP у тимчасові папки, запускає
два лаунчери, компільований тестовий процес із **тим самим C++ ClientConfig/INI та
побудовою команди сервера**, і справжній `coop-server.exe`. Перевіряються українські
ніки, лапки в паролях/назвах, відео/голосові налаштування, пароль після зміни в лобі,
фактична автентифікація ENet, сесійний нік/скін та повторний вхід у запущений сервер.
Цей тест не виконує рушій GTA, SCM-місії, завантаження ігрового світу чи моделі скінів.

Налаштування зберігаються в Electron userData, у `settings.json` (зокрема пароль лоббі).
Лаунчер створює `coop/launcher.ini`, зберігає невідомі параметри `coop/server.ini`
і використовує `coop/launcher-server-data/` для серверного профілю. Ваш `coop/coop.ini`
не переписується. Для LAN сервер отримує `internet = 0`.
